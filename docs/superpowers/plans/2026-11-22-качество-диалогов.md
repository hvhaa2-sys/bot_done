# План исправлений по разбору рабочих диалогов

Основание — [ручной разбор переписки и снимка базы](../../РАЗБОР-ДИАЛОГОВ-2026-11-22.md).

1. Воспроизвести поиск частного совета в другом ТЦ. Исключить старые общие факты из клиентской выдачи до проверки. В разделе «Обучение» дать менеджеру выбрать площадку, весь бизнес или только эту заявку. Проверить опубликованные версии, повтор формы и несовместимые площадки.
2. Воспроизвести ответ со списком цен без сроков. Восстановить период по подходящей строке прайса. Проверить неоднозначные суммы, неизвестный срок и отсутствие подстановки в бюджет клиента.
3. Воспроизвести сравнение Бутово на месяц с ВЕЕРом на неделю. Сохранить обе позиции в контексте сравнения и отличать вторую позицию от замены первой. Проверить обычный вход и восстановление диалога из истории.
4. Проверить в MAX сообщение с двумя задачами — справка по формату и подтверждение выполненной работы. Статус работы подтверждает менеджер, справочный ответ требует подходящего опубликованного источника.
5. Запустить целевые тесты, общий набор и экзамен без сети. Проверить реальные старые записи только на копии. Внести результаты проверок в журнал проекта. Обновление рабочего сервера требует отдельного решения владельца.

### Что размечает менеджер

В [таблице из 20 ситуаций](../../../eval/manager_review/dialogs_2026-11-22.csv) приведены обезличенные пересказы восьми чатов. На каждую строку заполняют последние три поля. Если сообщения достаточно для справки, записывают допустимый ответ и источник. Если нужно актуальное состояние сделки, указывают, кто его подтверждает. В смешанной просьбе можно заполнить оба поля. Для сообщения к сведению можно указать «ответ не нужен».

15 ситуаций доступны для разбора ошибок. Пять из четырёх других чатов оставлены для контроля. В контрольные примеры нельзя подмешивать будущий ответ менеджера или новый факт, полученный из этой же переписки. Набор был составлен после аудита, поэтому окончательную независимую оценку стоит повторить на новых обращениях. Строки не участвуют в автоматическом экзамене и не являются подтверждёнными правилами бизнеса.
