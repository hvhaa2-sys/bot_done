26 ноября у команды есть четыре предварительных материала: макет карточки, сверка по строкам релиза, набор из десяти вопросов и технический повтор установки. По каждому участник фиксирует собственную проверку и отзыв со своего аккаунта.

## 1. Карточка ошибочного черновика

Глеб поставил задачу. Правка доступна в отдельной ветке. Роман проверяет на учебных данных два пути: что видит менеджер при отклонённой сумме и что он может сделать с обычным черновиком. Фиксирует результат своими словами в PR с исправлением карточки.

## 2. Три спорных позиции

Данил сверяет радио «Глобуса», экраны ВЕЕР с января 2027 и R2 у О’КЕЙ. Выход — три строки с файлом, листом или страницей, расхождением и решением либо открытым вопросом. В новый файл попадают только фактически проверенные данные. Глеб описывает решение ядра для каждой позиции. Иван проверяет его вопросами с ожидаемым действием. Данил открывает PR со сверкой, Глеб оставляет отзыв. Иван добавляет 2–3 вопроса в `eval/questions.csv`, Данил проверяет их в отдельном PR. Если Глеб передаст обезличенную таблицу 17 пар, Данил отдельно укажет, какие интервалы подтвердил и где изменил бы разметку.

## 3. Поиск по десяти запросам

Владислав сам составляет десять вопросов и фиксирует ожидаемый источник до запуска поиска. Сохраняет список и результат BM25 при k=8. На каждый промах прикладывает вопрос и выдачу. Глеб получает воспроизводимый пример, исправляет поиск при необходимости. Владислав повторяет замер на том же наборе. Если все источники найдены сразу, записывает результат и получает независимый отзыв.

## 4. Установка на другой машине

Иван берёт чистый клон на своей машине, фиксирует коммит, время и первое затруднение. Режим mock, без рабочего .env и токенов Telegram/MAX. Роман или Глеб правит инструкцию по конкретной ошибке, Иван повторяет проблемный шаг и прикладывает результат. Иван публикует протокол в № 11 и оставляет свой отзыв в PR с документацией, в том числе если все шаги сработали сразу.

Состояния: «Нужно», «В работе», «На проверке», «Готово». При каждом переходе участник добавляет дату, ссылку и собственное имя. Статус этой доски показывает только подтверждённые действия.
