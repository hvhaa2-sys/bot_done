# Состав репозитория

22.10.2026 подготовлена актуальная версия проекта для приватного репозитория GitHub.
Создание удалённого репозитория требует входа в GitHub; SSH-доступ аккаунта `hvhaa2-sys` уже проверен.

Включены приложение, тесты, исходная база знаний, Docker и мастер настройки, исследовательский стенд,
документация, текущая презентация и папка `Итерации/`. Снимок в итерациях сохраняет точные байты
для проверки SHA-256 на разных ОС. Манифест и отобранные результаты BM25 включены явно.

Локально остаются `.env`, рабочие SQLite, импорт переписок, резервные копии, опубликованные снимки
рабочей базы, кеш векторов, временные сборки и прежняя презентация 14 октября.
Не добавляйте исключённые файлы командой `git add -f`.

## Запуск после клонирования

С установленными Docker Engine и Compose 2.30+:

```bash
./setup --demo --non-interactive
docker compose up -d --build --wait
```

Для настоящего подключения вместо demo используйте `./setup` и собственные ключи.
Инструкция, обновление и восстановление: [DOCKER.md](DOCKER.md).
В демонстрационном дистрибутиве есть материалы пилотного бизнеса; для другого бизнеса нужна его база.

## Проверки

```bash
python3.13 -m venv .venv
.venv/bin/python -m pip install --require-hashes -r requirements-dev.lock
make check
```

Перед первой загрузкой прошли Ruff и 511 автоматических тестов. Состав Git index проверен
Gitleaks и отдельно на точные значения действующих секретов, включая XML внутри презентаций.
Проверки не обращались к платной модели и не меняли рабочий Telegram.

Новая история Git начинается с текущего состояния. Прошлые даты и авторство отдельных этапов
не восстанавливались искусственно. Commit и push выполняются по прямой просьбе пользователя.
