Это порядок демонстраций и проверок, не история написания кода по неделям. Значительная часть уже существует
в текущем прототипе. К каждому следующему показу нужны новые проверенные данные, исправления по обратной связи
и результаты самостоятельной проверки команды. На вопрос о полной готовности отвечаем по фактическому состоянию.

## Ближайшая встреча

Открыть [план встречи](Первая_встреча.md), затем короткую презентацию в папке 01.
Показать один сценарий за 6–8 минут и оставить 5–10 минут на замечания преподавателя.
Полную презентацию на 16 слайдов держим для подробных вопросов и следующих встреч.

Для репетиции из корня проекта:

```bash
./Итерации/01_23-24_октября_Основа/показ
```

Все пять `показ` используют отдельные временные базы, без Telegram и запросов к модели.
Репетиция проверяет работу программного сценария. Возможности живого GigaChat демонстрируются отдельно,
если перед встречей проверены подключение и лимит. Записи репетиций лежат в папках `Материалы/`.

## Команда

В [КОМАНДА.md](КОМАНДА.md) предложены пять зон ответственности с результатами к каждой встрече.
Имена и прошлый вклад пока неизвестны. Таблица становится распределением личного вклада после согласования
с участниками и появления их материалов, проверок и исправлений.

## Что лежит рядом

- `Опорная_сборка_2026-10-22/`: одна копия текущих исходников, прайса, заметок и стенда поиска.
- `Опорная_сборка_2026-10-22/СБОРКА.json`: список файлов и SHA-256; сборка не перезаписывается.
- Пять отдельных папок: сценарий, приёмка, ответственность и команда `./показ`.
- Папка 04: настоящий предыдущий отчёт BM25 с ограничениями разметки.
- Папка 05: запись о предыдущем Docker smoke, отдельно от текущей файловой репетиции.

Рабочие `.env`, SQLite, история чатов и ключи в опорную сборку не включены.
Для репетиций используется `.venv` родительского проекта. Это рабочий комплект команды,
а не автономный установщик для чужого компьютера. Контейнерная установка описана в папке 05.

Не запускайте `собрать.py` повторно поверх готового комплекта: он специально откажется перезаписывать сборку.
Для следующей опорной версии нужна новая папка с действительной датой.
