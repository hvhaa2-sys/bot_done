# 2. Пополнение базы из ответов менеджера

Встреча: 2 ноября 2026 года, предварительно. Ведут: У2 и У3.

## Результат показа

Ответ менеджера сохраняется кандидатом и становится знанием после утверждения.

## Что уже есть на 22.10.2026

Сбор, очередь и утверждение уже прототипированы. До этой встречи нужна проверка на согласованных данных бизнеса, а не обещание написать всё заново.

## Сценарий на 5–8 минут

1. Показать вопрос, ответа на который ещё нет в учебной базе.
2. Добавить ответ менеджера и открыть кандидата с источником.
3. Проверить, что до утверждения кандидат не используется.
4. Утвердить факт и найти его по новой формулировке вопроса.

## Приёмка

- [ ] Исходный вопрос и ответ менеджера доступны для проверки.
- [ ] Неутверждённый и отклонённый кандидаты не попадают в рабочую выдачу.
- [ ] Личные договорённости и новые суммы не превращаются в общий прайс.
- [ ] 20 разрешённых пар вопрос–ответ проверены владельцем бизнеса; ошибки извлечения перечислены.

## Ответственность участников

- У1: согласовать с менеджером, какие ответы можно переносить в общие знания.
- У2: подготовить и разметить 20 разрешённых пар, исключить личные сведения.
- У3: проверить повторы, отклонение и неизвестные суммы, исправить найденные дефекты.
- У4: проверить группировку похожих вопросов и пограничные пары.
- У5: провести разбор очереди с пользователем, записать время и неудобные места.
