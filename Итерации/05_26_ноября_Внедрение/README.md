# 5. Запуск другим участником и проверка внедрения

Встреча: 26 ноября 2026 года, предварительно. Ведут: У5 и У1.

## Результат показа

Человек, не настраивавший проект, запускает его по инструкции и восстанавливает данные.

## Что уже есть на 22.10.2026

Docker, мастер и резервирование готовы. Реальный smoke 21.10 прошёл на отдельной VM. Независимое внедрение и экономический эффект пилота ещё предстоит подтвердить.

## Сценарий на 5–8 минут

1. Запустить релиз на чистом компьютере после установки Docker.
2. Пройти настройку и показать подключение материалов нового бизнеса.
3. Создать полный бэкап, изменить данные и восстановить SQLite вместе с версиями знаний.
4. Показать доступные измерения пилота и ограничения, согласовать объём защиты.

## Приёмка

- [ ] Запуск повторён другим участником по двум документированным командам.
- [ ] Пересоздание контейнера не теряет состояние.
- [ ] Восстанавливаются SQLite, знания и версии, а не только одна база данных.
- [ ] Пилотные результаты отделены от плановых метрик и демонстрационных данных.
- [ ] Если пилот не состоялся, это явно указано и экономию времени не придумывают.

## Ответственность участников

- У1: провести согласованный пилот и сравнить его с исходной перепиской.
- У2: повторить наполнение базы по материалам нового бизнеса.
- У3: разобрать сбои и ошибки, найденные на чистой установке.
- У4: оформить итог исследования и условия, при которых выбран метод поиска.
- У5: выполнить независимую установку, полный backup/restore и подготовить инструкцию передачи.
