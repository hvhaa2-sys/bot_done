# Как передать задачу участнику команды

Выберите карточку на [доске КТ](docs/ЗАДАЧИ-КТ.md) и зафиксируйте, кто примет результат.
Назовите ветку по схеме имя/задача. Приложите к PR исходный вопрос, данные или макет.
Покажите конкретное изменение и укажите, где его увидит следующий участник.

Для локальной проверки возьмите отдельный клон без рабочего .env.
Установите зависимости из requirements-dev.lock в .venv и выберите LLM_PROVIDER=mock.
Проверьте, что Settings.load() возвращает пустые токены Telegram и MAX.
Запустите make check и .venv/bin/python -m eval.ci_gate.
Для проверки без мессенджеров используйте тесты на учебных данных.

В PR укажите команды и результат, использование ИИ и собственные правки.
Попросите второго участника воспроизвести пример и оставить отзыв со своего аккаунта.
После приёмки свяжите задачу, PR, отзыв и результат в карточке.
